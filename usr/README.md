# Medical App

A comprehensive doctor appointment and medicine reminder app.

## Features
- User Authentication (Login & Signup)
- Main Dashboard with upcoming appointments
- Doctor Search & Booking flow
- Payment & Booking Confirmation Slip
- Medical History & Medicine Reminders

## Tech Stack
- Flutter
- Supabase (Auth/Database placeholder)

## Setup
1. Run `flutter pub get`
2. Run `flutter run`
